Fonte e colunas

De onde a query lê e o que ela projeta.

Tabela e fonte

Db.Table('users')                       // alias de From
Db.From('users')
Db.Table('users').FromAs('users', 'u')  // com alias
Db.Table('users').WithSchema('app')     // prefixa o schema
SQL
select * from `users`
select * from `users`
select * from `users` as `u`
select * from `app`.`users`

Subquery e SQL cru como fonte:

Sub := Db.Query.Table('logs').Select(['user_id']).Where('level', 'error');
Db.Query.FromSub(Sub, 'e').Select(['e.user_id']);

Db.Query.FromRaw(Db.Raw('`users` force index (`pk`)', []));
SQL
select `e`.`user_id` from (select `user_id` from `logs` where `level` = ?) as `e`
select * from `users` force index (`pk`)
⚠
Alias obrigatório

Subquery como fonte exige alias: compilar sem ele levanta ELzNexCompile mencionando alias. É restrição do SQL, não do LzNex.

Db.Query cria uma query sem tabela — é assim que se monta uma subquery para passar a FromSub, WhereInSub, JoinSub ou Union. AsAlias define o alias que a query usa quando é consumida como subquery.

Colunas

Db.Table('users')                                  // sem Select: tudo
Db.Table('users').Select(['id', 'name'])
Db.Table('users').Select(['users.id'])             // nome qualificado
Db.Table('users').Select(['name as nick'])         // alias na propria string
Db.Table('users').SelectAs('name', 'nick')         // alias explicito
Db.Table('users').Column('email')                  // uma coluna
Db.Table('users').Distinct.Select(['country'])
SQL
select * from `users`
select `id`, `name` from `users`
select `users`.`id` from `users`
select `name` as `nick` from `users`
select `name` as `nick` from `users`
select `email` from `users`
select distinct `country` from `users`

Expressão crua e subquery

Db.Table('users').SelectRaw('count(*) + ?', [5]);

Sub := Db.Query.Table('posts').Aggregate(agMax, 'id');
Db.Table('users').SelectSub(Sub, 'last_post');
SQL
select count(*) + ? from `users`
select (select max(`id`) from `posts`) as `last_post` from `users`

binds do primeiro: 5

DistinctOn

Db.Table('users').DistinctOn(['country']);
// ELzNexCompile: 'distinct on' nao existe em MySQL
Db.Table('users').DistinctOn(['country']).Select(['country', 'name']);
// select distinct on ("country") "country", "name" from "users"
