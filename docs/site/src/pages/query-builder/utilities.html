Clone, clear e ToSQL

Reaproveitar uma query montada, limpar um grupo de cláusulas e inspecionar o SQL.

function Clone: ILzNexQueryCopia profunda e independente: alterar a cópia não afeta o original, nem o contrário.
function Clear(const AGroup: TLzNexStatementGroup): ILzNexQueryRemove todos os statements de um grupo (sgWhere, sgOrder, sgColumns…).
function ToSQL: TLzNexFragmentTexto + binds, sem conexão. Levanta se houver grupo aberto.
function ToSQLString: stringSQL com os valores interpolados. Só para log.
function Transacting(const ATrx: ILzNexTransaction): ILzNexQueryAmarra a query a uma transação (queries criadas a partir de Trx já vêm amarradas).
function OpenGroupCount: IntegerQuantos grupos de predicado ainda estão abertos.
function Ast: TLzNexAstA árvore acumulada. O builder continua dono: não liberar, não guardar além do escopo.
 
Base := Db.Table('users').Where('active', True);

Ativos   := Base.Clone.OrderBy('name').Get;
Contagem := Base.Clone.Count;
Pagina   := Base.Clone.Page(2, 20).Get;

// trocar a ordenacao sem remontar
Q := Db.Table('users').OrderBy('name');
Q.Clear(sgOrder).OrderByDesc('created_at');
SQL
select * from `users` where `active` = ? order by `name` asc
select count(*) from `users` where `active` = ? limit ?
select * from `users` where `active` = ? limit ? offset ?
select * from `users` order by `created_at` desc
⚠
Terminal consome a query

O terminal grava o verbo na árvore (qmSelect, qmInsert…) e executa. Reaproveitar a mesma instância para outro verbo depois disso mistura estado; o caminho certo é Clone antes de cada terminal, como no exemplo acima.

Inspecionar sem executar

F := Db.Table('users').Where('id', 7).ToSQL;
Writeln(F.Text);                      // select * from `users` where `id` = ?
Writeln(F.Bindings.Count);            // 1
Writeln(F.Bindings.Describe);         // [integer(7)]
Writeln(Db.Table('users').Where('id', 7).ToSQLString);  // so para log
