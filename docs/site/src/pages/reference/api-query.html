ILzNexQuery

A interface do query builder, método por método. Tudo devolve ILzNexQuery — exceto os Join*, OnConflict e os terminais.

Toda chamada que devolve ILzNexQuery devolve a mesma instância, não uma cópia: o encadeamento acumula na árvore. Para ramificar, use Clone. Os exemplos com SQL de cada família estão nas páginas de guia — Fonte e colunas, Where, Joins, Agrupar e ordenar, Union e CTE, Executar e ler, Insert e update.

Fonte

A fonte é um campo único da árvore: chamar duas vezes substitui, não acumula. AsAlias nomeia a query inteira (útil quando ela vira subquery de outra); FromAs nomeia a tabela.

function FromSub(const ASub: ILzNexQuery; const AAlias: string): ILzNexQuerySubquery como fonte. O alias é obrigatório: sem ele, levanta ELzNexBuilder.
function FromRaw(const ARaw: ILzNexRaw): ILzNexQueryFonte vinda de um template cru (Db.Raw).
function WithSchema(const ASchema: string): ILzNexQueryQualifica a tabela com um schema.
function AsAlias(const AAlias: string): ILzNexQueryAlias da query como um todo.

Where

O conector (and / or) e a negação são parâmetros de cada predicado, não estado do builder: um OrWhere afeta só o predicado que ele introduz. O operador passa por uma lista fechada — fora dela, ELzNexBuilder.

JSON e texto completo

Dependem de capacidade do dialeto: SupportsJson é falso no Firebird e SupportsFullText é falso em Firebird e SQLite — nesses casos o builder recusa antes de gerar SQL, com mensagem dizendo a alternativa.

function WhereJsonContains(const AColumn, APath: string; const AValue: TLzNexValue): ILzNexQueryPergunta se o documento contém o valor; caminho vazio = documento inteiro.
function WhereJsonLength(const AColumn, APath, AOp: string; const AValue: Integer): ILzNexQueryCompara o tamanho do array.
function WhereFullText(const AColumns: array of string; const ASearch: string): ILzNexQueryBusca de texto completo; exige o índice criado por ILzNexTable.FullText. O overload com TLzNexFullTextMode escolhe entre ftNatural e ftBoolean.
⚠
O caminho JSON não é bind

Nenhum banco aceita o caminho como parâmetro: ele vai no texto do SQL. Por isso o builder o valida contra uma lista fechada de caracteres — letra, dígito, _, $, . e índice entre colchetes — e levanta ELzNexBuilder em qualquer outro. Caminho vindo de entrada de usuário sem essa checagem seria injeção de SQL.

Join

Todos devolvem ILzNexJoin, que herda esta interface — daí poder encadear On* e continuar a query na mesma expressão. A exceção é JoinRaw: o texto cru já traz a cláusula ON, então não há o que encadear e ele devolve ILzNexQuery. Os métodos On* estão em Join e upsert.

Paginação e travamento

Limit e Offset recusam valor negativo, e Page é 1-based — os três levantam ELzNexBuilder em vez de gerar SQL estranho.

function Limit(const ACount: Int64): ILzNexQueryEntra como bind, não interpolado.
function Offset(const ACount: Int64): ILzNexQueryTambém bind.
function Page(const APage, APerPage: Int64): ILzNexQueryLimit(APerPage) + Offset((APage - 1) * APerPage). Página começa em 1.
function ClearPaging: ILzNexQueryDesfaz Limit/Offset. Clear não serve: limite e offset não são um grupo da árvore.
function ForUpdate: ILzNexQueryfor update; with lock no Firebird. Levanta no SQLite, que não tem lock de linha.
function ForShare: ILzNexQueryfor share. Levanta em Firebird (o with lock é sempre exclusivo) e em SQLite.
function SkipLocked: ILzNexQueryModificador de espera: pula linha travada. No Firebird sai with lock skip locked, sintaxe do 5 em diante.
function NoWait: ILzNexQueryModificador de espera: falha em vez de esperar. Levanta no Firebird, onde esperar é atributo da transação.

Os três paginadores

Estes executam e devolvem a janela com os metadados. Veja Paginação para quando usar cada um.

function Paginate(const APage, APerPage: Int64): TLzNexPageDuas queries: count num clone sem ordem nem janela, e a página — também num clone, então a janela não fica na query. Com group by, having, union ou Distinct, o count vai numa subquery.
function SimplePaginate(const APage, APerPage: Int64): TLzNexSimplePageUma query, com limit APerPage + 1: a linha extra responde HasMorePages e é descartada. Roda num clone.
function CursorPaginate(const APerPage: Int64; const ACursor: string = ''): TLzNexCursorPageKeyset. Exige OrderBy; recusa OrderByRaw, ordem de nulos explícita, coluna de ordenação fora do Select e valor nulo na chave. Cursor vazio começa do início. O corte e a inversão da ordem vão num clone, e o escopo passa por GroupWhere — paginar a mesma query num laço não acumula corte.
function Chunk(const ASize: Int64): ILzNexChunksLotes por limit/offset. Exige OrderBy.
function ChunkById(const ASize: Int64; const AKeyColumn: string = 'id'): ILzNexChunksLotes por chave > última lida. Ignora o OrderBy da query e não se perde se o conjunto mudar no meio. O avanço entra depois de GroupWhere, para valer também num escopo com or.
function Each(const AHandler: TLzNexRowProc; const AChunkSize: Int64 = 1000; const AKeyColumn: string = 'id'): Int64ChunkById + handler linha por linha; devolve quantas visitou. O handler é ponteiro de método, com var AStop para interromper.

function WithRecursive(const AAlias: string; const ASub: ILzNexQuery): ILzNexQueryCTE recursiva.
function HintComment(const AHint: string): ILzNexQueryHint em comentário /*+ ... */ depois do verbo. Hint com */ dentro levanta ELzNexBuilder.
function OnConflict(const AColumns: array of string): ILzNexOnConflictColunas de conflito do upsert. Lista vazia é válida no Postgres (on conflict do nothing).

Terminais

Terminal grava o verbo na árvore e executa — a execução nunca é efeito colateral de usar o objeto. Depois de um terminal, a instância carrega o verbo: para outro terminal, parta de um Clone. ToSQL e ToSQLString são os únicos que não precisam de conexão.

function ToSQLString: stringSQL com os valores já interpolados. Só para log — nunca mande ao banco.
function Dump: ILzNexQueryDespeja ToSQLString no logger da configuração (ou em stdout, se não houver) e devolve a própria query, para seguir a cadeia.
function Get: ILzNexResultExecuta o select e devolve o cursor forward-only.
function First: ILzNexRowPrimeira linha materializada, ou nil. Sem janela própria, o limit 1 vai num clone — a query de quem chamou não fica limitada.
function Value(const AColumn: string): TLzNexValueTroca a lista de colunas pela informada e devolve o escalar da primeira linha. Sem linha: Null.
function Scalar: TLzNexValuePrimeira coluna da primeira linha, sem mexer no select.
function Pluck(const AColumn: string): TLzNexValuesUma coluna de todas as linhas, como array.
function FirstOrFail: ILzNexRowComo First, mas levanta ELzNexQuery quando nada casa.
function Sole: ILzNexRowPede limit 2 e exige exatamente uma linha: levanta se nenhuma e levanta se duas.
function Exists: Booleanlimit 1 num clone e testa se veio linha.
function DoesntExist: BooleanO complemento de Exists.
function Count: Int64Atalho para Aggregate(agCount, '*').AsInt64.
function Aggregate(const AAgg: TLzNexAggregate; const AColumn: string): TLzNexValueagCount, agMin, agMax, agSum, agAvg. Roda num clone, sem a ordenação (com group by a ordem fica, porque ali ela decide qual grupo volta).

function InsertGetId(const AValues: TLzNexNamedValues): Int64Insere e devolve o id gerado. Onde há RETURNING, lê do próprio insert; onde não há, pergunta ao banco na mesma conexão. Assume a chave id.
function InsertGetId(const AValues: TLzNexNamedValues; const AIdColumn: string): Int64Idem, quando a chave tem outro nome.
function InsertMany(const ARows: array of TLzNexNamedValues): Int64Um insert com várias tuplas de values.

⚠
Query de NewQuery não executa

Uma query criada por NewQuery(Client) só constrói SQL: ela não conhece facade nem pool. Chamar um terminal que precisa de conexão levanta ELzNexBuilder dizendo isso. Para executar, parta de Db.Table(...) ou Db.Query.
