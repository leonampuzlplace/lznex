ILzNexQuery

A interface do query builder, método por método. Tudo devolve ILzNexQuery — exceto os Join*, OnConflict e os terminais.

Toda chamada que devolve ILzNexQuery devolve a mesma instância, não uma cópia: o encadeamento acumula na árvore. Para ramificar, use Clone. Os exemplos com SQL de cada família estão nas páginas de guia — Fonte e colunas, Where, Joins, Agrupar e ordenar, Union e CTE, Executar e ler, Insert e update.

Fonte

A fonte é um campo único da árvore: chamar duas vezes substitui, não acumula. AsAlias nomeia a query inteira (útil quando ela vira subquery de outra); FromAs nomeia a tabela.

function From(const AName: string): ILzNexQueryIdêntico a Table.
function FromAs(const AName, AAlias: string): ILzNexQueryTabela com alias.
function FromSub(const ASub: ILzNexQuery; const AAlias: string): ILzNexQuerySubquery como fonte. O alias é obrigatório: sem ele, levanta ELzNexBuilder.
function FromRaw(const ARaw: ILzNexRaw): ILzNexQueryFonte vinda de um template cru (Db.Raw).
function WithSchema(const ASchema: string): ILzNexQueryQualifica a tabela com um schema.
function AsAlias(const AAlias: string): ILzNexQueryAlias da query como um todo.

Where

O conector (and / or) e a negação são parâmetros de cada predicado, não estado do builder: um OrWhere afeta só o predicado que ele introduz. O operador passa por uma lista fechada — fora dela, ELzNexBuilder.

Join

Todos devolvem ILzNexJoin, que herda esta interface — daí poder encadear On* e continuar a query na mesma expressão. A exceção é JoinRaw: o texto cru já traz a cláusula ON, então não há o que encadear e ele devolve ILzNexQuery. Os métodos On* estão em Join e upsert.

Paginação e travamento

Limit e Offset recusam valor negativo, e Page é 1-based — os três levantam ELzNexBuilder em vez de gerar SQL estranho.

function Page(const APage, APerPage: Int64): ILzNexQueryLimit(APerPage) + Offset((APage - 1) * APerPage). Página começa em 1.

Terminais

Terminal grava o verbo na árvore e executa — a execução nunca é efeito colateral de usar o objeto. Depois de um terminal, a instância carrega o verbo: para outro terminal, parta de um Clone. ToSQL e ToSQLString são os únicos que não precisam de conexão.

function Count: Int64Atalho para Aggregate(agCount, '*').AsInt64.

function InsertGetId(const AValues: TLzNexNamedValues): Int64Insere e devolve o id gerado. Onde há RETURNING, lê do próprio insert; onde não há, pergunta ao banco na mesma conexão. Assume a chave id.

⚠
Query de NewQuery não executa

Uma query criada por NewQuery(Client) só constrói SQL: ela não conhece facade nem pool. Chamar um terminal que precisa de conexão levanta ELzNexBuilder dizendo isso. Para executar, parta de Db.Table(...) ou Db.Query.
