Schema

Referência de ILzNexSchema, ILzNexTable e das duas interfaces de definição que o compilador de DDL lê.

ILzNexSchema

Ponto de entrada do DDL, obtido em Db.Schema. CreateTable devolve um builder em modo create e Table um builder em modo alter — é o TableMethod que decide quais métodos são válidos adiante.

function WithSchema(const AName: string): ILzNexSchemaFixa o schema/catálogo usado pelas tabelas criadas depois desta chamada. Altera o próprio builder e devolve ele mesmo.
function CreateTable(const AName: string): ILzNexTableBuilder em modo create. Nome vazio levanta ELzNexSchema.
function Table(const AName: string): ILzNexTableBuilder em modo alter da tabela existente.
function HasTable(const AName: string): BooleanConsulta information_schema.tables com a tabela (e o schema, se houver) como bind.
function HasColumn(const ATable, AColumn: string): BooleanO mesmo em information_schema.columns.
procedure DropTable(const AName: string)drop table. Tabela ausente é erro do banco.
procedure DropTableIfExists(const AName: string)drop table if exists.
procedure RenameTable(const AFrom, ATo: string)Renomeia pelo SQL do dialeto.
procedure Truncate(const AName: string)truncate table.
procedure Raw(const ASQL: string; const AArgs: array of const)Escapatória: manda o DDL direto pela fachada, com a mesma gramática de binds do SQL cru.
ℹ
Tudo aqui precisa de conexão

Um ILzNexSchema criado em modo somente-SQL (sem ILzNex) ainda monta builders e gera DDL por ToSQL, mas HasTable, DropTable, Raw e companhia levantam ELzNexSchema por não terem onde executar.

ILzNexTable

Um builder só, usado tanto para create table quanto para alter table. Todos os métodos devolvem ILzNexTable para encadear.

Colunas

Cada chamada empurra uma coluna nova e passa a ser a última coluna, que é o alvo dos modificadores da subtabela seguinte. Toda coluna nasce nullable; as duas de incremento são a exceção.

function Increments(const AName: string = 'id'): ILzNexTableInteiro auto-incremento. Já vem not null, unsigned, auto-increment e chave primária.
function BigIncrements(const AName: string = 'id'): ILzNexTableO mesmo em 64 bits.
function TinyInt(const AName: string): ILzNexTableInteiro pequeno.
function SmallInt(const AName: string): ILzNexTableInteiro pequeno.
function Int(const AName: string): ILzNexTableInteiro.
function BigInt(const AName: string): ILzNexTableInteiro de 64 bits.
function Bool(const AName: string): ILzNexTableBooleano.
function Decimal(const AName: string; const APrecision: Integer = 8; const AScale: Integer = 2): ILzNexTableDecimal exato. Precisão <= 0 gera decimal sem parâmetro.
function Float(const AName: string): ILzNexTablePonto flutuante simples.
function Double(const AName: string): ILzNexTablePonto flutuante duplo.
function Char_(const AName: string; const ALength: Integer = 255): ILzNexTableTexto de largura fixa. O sublinhado existe porque char é palavra reservada.
function Str(const AName: string; const ALength: Integer = 255): ILzNexTablevarchar.
function Text(const AName: string): ILzNexTableTexto longo.
function MediumText(const AName: string): ILzNexTableTexto médio.
function LongText(const AName: string): ILzNexTableTexto muito longo.
function Binary(const AName: string; const ALength: Integer = 0): ILzNexTableBinário de largura fixa.
function Blob(const AName: string): ILzNexTableBinário longo.
function Date(const AName: string): ILzNexTableData.
function Time(const AName: string): ILzNexTableHora.
function DateTime(const AName: string): ILzNexTableData e hora.
function Timestamp(const AName: string): ILzNexTableTimestamp.
function Json(const AName: string): ILzNexTableDocumento JSON.
function Uuid(const AName: string): ILzNexTableUUID. Onde não há tipo nativo, cai em texto de 36.
function Enum(const AName: string; const AItems: array of string): ILzNexTableLista fechada de valores. Lista vazia levanta ELzNexSchema.
function Specific(const AName, ATypeSQL: string): ILzNexTableTipo escrito à mão, interpolado como está no DDL. Tipo vazio levanta.
function Timestamps(const ADefaultNow: Boolean = True): ILzNexTableCria created_at e updated_at. Com True as duas ficam not null com default CURRENT_TIMESTAMP.

Modificadores

Agem sobre a última coluna adicionada — não há parâmetro de coluna. Chamados sem coluna anterior (ou depois de um DropColumn/RenameColumn, que limpam a referência) levantam ELzNexSchema com o nome do modificador.

function NotNull: ILzNexTableRemove o nullable que toda coluna recebe ao nascer.
function Nullable: ILzNexTableDevolve o nullable (útil depois de um NotNull).
function Unsigned: ILzNexTableSem sinal, onde o dialeto suporta.
function Default_(const AValue: TLzNexValue): ILzNexTableDefault literal. Um TLzNexValue não setado levanta — para NULL explícito use TLzNexValue.Null.
function DefaultRaw(const ASQL: string): ILzNexTableDefault como expressão SQL (CURRENT_TIMESTAMP, uuid_generate_v4()). SQL vazio levanta.
function Comment(const AText: string): ILzNexTableComentário da coluna. Em dialeto sem comentário inline, vira statement separado no plano.
function Collate(const AName: string): ILzNexTableCollation da coluna.
function After(const AColumn: string): ILzNexTablePosiciona a coluna, onde o dialeto suporta.
function Primary: ILzNexTableEntra a última coluna na chave primária. Chamadas repetidas acumulam no mesmo índice primário em vez de criar vários.
function Unique: ILzNexTableÍndice único de uma coluna.
function Index: ILzNexTableÍndice comum de uma coluna.
function Change: ILzNexTableMarca a coluna como alteração em vez de inclusão. Só em modo alter.

Chave estrangeira e índices

References abre uma FK sobre a última coluna e passa a ser o alvo de InTable, OnDelete e OnUpdate. Os métodos com lista de colunas criam índices independentes da coluna corrente.

function References(const AColumn: string): ILzNexTableColuna referenciada. Aceita 'users.id', que já preenche a tabela.
function InTable(const ATable: string): ILzNexTableTabela referenciada. Sem References antes, levanta.
function OnDelete(const AAction: string): ILzNexTableAção de exclusão. A lista é fechada: cascade, restrict, set null, no action, set default — ela é interpolada no DDL, não vira bind.
function OnUpdate(const AAction: string): ILzNexTableO mesmo na atualização.
function ConstraintName(const AName: string): ILzNexTableNome explícito para o último índice ou FK, no lugar do nome derivado.
function Primary(const AColumns: array of string): ILzNexTableChave primária composta. Lista vazia levanta.
function Unique(const AColumns: array of string): ILzNexTableÍndice único composto.
function Index(const AColumns: array of string): ILzNexTableÍndice composto.
function DropColumn(const AName: string): ILzNexTableRemove coluna. Só em alter.
function DropIndex(const AColumns: array of string): ILzNexTableRemove índice pelo nome derivado das colunas. Só em alter.
function DropUnique(const AColumns: array of string): ILzNexTableRemove índice único. Só em alter.
function DropForeign(const AColumns: array of string): ILzNexTableRemove FK. Só em alter.
function DropPrimary: ILzNexTableRemove a chave primária. Só em alter.
function RenameColumn(const AFrom, ATo: string): ILzNexTableRenomeia coluna. Só em alter; os dois nomes são obrigatórios.

Opções de tabela

Valem apenas em create table: num builder em modo alter levantam ELzNexSchema, porque opção de tabela não pertence a um alter aqui. Dialeto que não conhece a opção simplesmente a ignora na compilação.

function Engine(const AName: string): ILzNexTableEngine de armazenamento.
function Charset(const AName: string): ILzNexTableCharset da tabela.
function TableCollate(const AName: string): ILzNexTableCollation da tabela. O nome difere de Collate, que é da coluna.
function TableComment(const AText: string): ILzNexTableComentário da tabela.

Terminais

function ToSQL: TLzNexDdlPlanCompila sem executar. Devolve o plano com Pre, Statements e Post — um DDL pode precisar de mais de um comando.
function Execute: IntegerExecuta ToSQL.All em ordem, na mesma conexão, e devolve quantos comandos rodaram. Num builder sem ILzNex levanta ELzNexSchema.
⚠
Execute não é atômico por conta própria

Os comandos do plano vão um a um. Em dialeto onde DDL dá commit implícito (DdlIsTransactional falso), falhar no terceiro comando deixa os dois primeiros aplicados — envolver numa transação não desfaz. Veja migrations.

Leitura

Estes métodos existem para o compilador de DDL: é por eles que um ILzNexSchemaCompiler lê o que o builder acumulou. Também servem para testar o builder sem banco.

function TableName: stringNome da tabela, sem quote.
function SchemaName: stringSchema herdado do WithSchema, ou vazio.
function TableMethod: TLzNexTableMethodtmCreate ou tmAlter — decide qual rotina do compilador roda.
function ColumnCount: IntegerQuantidade de colunas acumuladas, incluindo as marcadas como drop.
function ColumnAt(const AIndex: Integer): ILzNexColumnDefColuna na ordem de inclusão. Índice fora da faixa levanta.
function IndexCount: IntegerQuantidade de índices e FKs.
function IndexAt(const AIndex: Integer): ILzNexIndexDefÍndice ou FK na ordem de inclusão.
function RenamedColumns: TLzNexNamedValuesPares nome antigo → nome novo registrados por RenameColumn.
function EngineName: stringEngine pedida, ou vazio.
function CharsetName: stringCharset pedido, ou vazio.
function CollateName: stringCollation da tabela, ou vazio.
function CommentText: stringComentário da tabela, ou vazio.
function Client: ILzNexClientDialeto do builder. ToSQL sem dialeto levanta.

ILzNexColumnDef e ILzNexIndexDef

São as duas interfaces que o compilador de DDL consome: o builder só acumula, e quem traduz tipo, modificador e índice para texto é o ILzNexSchemaCompiler do dialeto. Interessam a quem escreve um dialeto novo — veja dialetos. Quem apenas usa o schema não toca nelas.

function ColumnName: stringNome da coluna, sem quote.
function ColumnType: TLzNexColumnTypeTipo lógico. O compilador traduz em ColumnTypeSQL.
function Param1: IntegerPrimeiro parâmetro do tipo: comprimento, ou precisão no decimal.
function Param2: IntegerSegundo parâmetro: escala do decimal.
function EnumItems: TLzNexValuesItens do enum. Vazio nos outros tipos.
function SpecificType: stringTexto do tipo em ctSpecific.
function HasModifier(const AMod: TLzNexColumnModifier): BooleanConsulta um modificador. O compilador percorre ModifierOrder chamando isto.
function DefaultValue: TLzNexValueDefault. Pode ser um valor, um vkRaw (de DefaultRaw) ou não setado.
function CommentText: stringComentário da coluna.
function CollateName: stringCollation da coluna.
function AfterColumn: stringColuna de referência do After.
function IsChange: BooleanVerdadeiro quando vem de Change: é alteração, não inclusão.
function IsDrop: BooleanVerdadeiro quando vem de DropColumn. Nesse caso só o nome importa.

ILzNexIndexDef cobre índice, único, primária e FK no mesmo formato — é o IndexKind que diferencia, e os quatro campos de referência só vêm preenchidos em ixForeign.

function IndexKind: TLzNexIndexKindixIndex, ixUnique, ixPrimary ou ixForeign.
function Columns: TLzNexValuesColunas locais, como identificadores. Vazio num DropPrimary.
function IndexNameOverride: stringNome vindo de ConstraintName. Vazio significa "derive o nome".
function RefTable: stringTabela referenciada. Vazio fora de FK.
function RefColumns: TLzNexValuesColunas referenciadas.
function OnDeleteAction: stringAção de exclusão, já normalizada em minúsculas.
function OnUpdateAction: stringAção de atualização, já normalizada.
function IsDrop: BooleanVerdadeiro nos Drop*: o compilador emite a remoção em vez da criação.
