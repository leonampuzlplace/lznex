Resultados

ILzNexResult é o cursor que o banco devolve; ILzNexRow é uma linha já copiada para a memória.

A diferença entre os dois é quem é dono dos dados. O cursor lê a linha corrente direto do driver — avança para frente e nunca volta. A linha é um retrato: copiada no momento em que você pede, ela continua válida depois de o cursor avançar ou fechar.

ILzNexResult

Cursor forward-only. Next posiciona na próxima linha e devolve False quando acaba — ler coluna antes do primeiro Next levanta ELzNexQuery dizendo exatamente isso.

function Next: BooleanAvança uma linha. False no fim (e também se o cursor já estiver fechado).
function Field(const AName: string): TLzNexValueColuna da linha corrente, por nome.
function FieldAt(const AIndex: Integer): TLzNexValueColuna por posição, base 0. Fora da faixa levanta.
function FieldCount: IntegerQuantas colunas o resultado tem. Pode ser lido antes do primeiro Next.
function FieldName(const AIndex: Integer): stringNome da coluna na posição. É o label do driver: com alias, vem o alias.
function CurrentRow: ILzNexRowCopia a linha corrente para um ILzNexRow independente do cursor.
function ToRows: TLzNexRowArrayConsome o resto do cursor em um array de linhas.
function ToJSON: stringConsome o resto do cursor em um array JSON. NULL vira null, bytes viram base64.
procedure CloseFecha o cursor e libera o empréstimo da conexão. Idempotente.

ToRows e ToJSON partem da posição atual e incluem a linha corrente: se você já chamou Next, aquela linha entra no resultado; se não, eles mesmos avançam. Os dois esvaziam o cursor — um Next depois deles devolve False.

⚠
O cursor segura uma vaga do pool

O ILzNexResult carrega o empréstimo da conexão: enquanto ele vive, a conexão não volta para o pool. Isso é necessário — ler a próxima linha é conversa com o servidor, não leitura de buffer local — mas significa que um cursor guardado em campo de objeto de vida longa tira uma conexão do pool até lá. A devolução acontece no Close ou quando a última referência ao resultado sai de escopo.

Em laço curto, não há o que fazer. Em código que vai segurar os dados, materialize e solte: ToRows (ou First no builder, que já fecha o cursor antes de devolver a linha).

ILzNexRow

Linha materializada, sem vínculo com conexão nem com o cursor de origem. É o que First e ToRows devolvem.

function Field(const AName: string): TLzNexValueColuna por nome. Levanta se não existir.
function TryField(const AName: string; out AValue: TLzNexValue): BooleanNão levanta: devolve False e deixa AValue como Unset.
function FieldAt(const AIndex: Integer): TLzNexValueColuna por posição, base 0. Fora da faixa levanta.
function Has(const AName: string): BooleanA coluna existe nesta linha?
function FieldCount: IntegerQuantas colunas a linha tem.
function FieldName(const AIndex: Integer): stringNome da coluna na posição.
function ToJSON: stringUm objeto JSON com as colunas da linha.
ℹ
Field levanta e diz quais colunas existem

Coluna inexistente em Field levanta ELzNexQuery com a lista das colunas que o resultado tem — o erro mais comum é alias esquecido ou errado, e a lista resolve na primeira leitura da mensagem, sem precisar imprimir o SQL. Quando a ausência é esperada (select que varia, coluna opcional), use TryField ou Has, que não levantam.

A busca por nome tenta primeiro o nome exato e só depois ignora a caixa: Field('ID') acha id, mas se houver id e ID no mesmo resultado, cada um é achado pelo seu nome exato.

As janelas de paginação

Os três paginadores devolvem record, não interface: são retratos de uma consulta já feita, sem nada para liberar. As linhas vêm em TLzNexRowArray — já materializadas, com o cursor fechado. Veja Paginação.

RecordCamposMétodos
TLzNexPage Rows, Total, PerPage, CurrentPage Count, LastPage, HasMorePages, IsEmpty
TLzNexSimplePage Rows, PerPage, CurrentPage, HasMorePages Count, IsEmpty
TLzNexCursorPage Rows, PerPage, NextCursor, PrevCursor Count, HasMorePages, IsEmpty

LastPage é ceil(Total / PerPage) calculado em inteiros, e nunca menos que 1 — uma lista vazia ainda é uma página (vazia). Em TLzNexCursorPage, HasMorePages é simplesmente NextCursor <> ''.

ILzNexChunks

A varredura em lotes. Cada Next roda uma query, materializa o lote e fecha o cursor antes de devolver — nenhuma conexão do pool fica presa entre dois lotes.

function Next: BooleanCarrega o próximo lote; False quando acabou.
function Rows: TLzNexRowArrayAs linhas do lote corrente.
function ChunkIndex: Int64Número do lote, 1-based; zero antes do primeiro Next.
function RowsSeen: Int64Total de linhas lidas até agora.

O handler de Each é TLzNexRowProc: procedure(const ARow: ILzNexRow; var AStop: Boolean) of object. É ponteiro de método porque o FPC 3.2 não tem função anônima — o destino tem de ser um método de alguma classe.

TLzNexValue — AsString, AsInt64, IsNull e os demais acessores — está em Valores.
