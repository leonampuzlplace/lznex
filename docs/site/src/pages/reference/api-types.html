Value, Fragment e Bindings

Os três records que carregam dado, texto e parâmetro por toda a biblioteca. São records, não classes: não há refcount nem Free envolvido.

TLzNexValue

Um valor tagueado. O campo Kind diz qual dos quinze formatos está preenchido, e é isso que o compilador consulta para decidir entre emitir um ?, um identificador quotado ou o texto de um SQL cru. Declarado em LzNex.Value e reexportado por LzNex.

Construtores nomeados

Todos são class function ... static, então a chamada é TLzNexValue.FromInteger(1), sem instância.

class function Unset: TLzNexValue; staticO estado zero (vkUnset). É o que um TLzNexValue não inicializado contém, e é por isso que ele existe: dá um nome ao acidente.
class function Null: TLzNexValue; staticNULL do SQL. Diferente de Unset: Null é bindável, Unset não.
class function FromBoolean(const AValue: Boolean): TLzNexValue; staticvkBoolean.
class function FromInteger(const AValue: Integer): TLzNexValue; staticvkInteger.
class function FromInt64(const AValue: Int64): TLzNexValue; staticvkInt64. Guarda no mesmo campo interno de FromInteger; o Kind é que difere.
class function FromFloat(const AValue: Double): TLzNexValue; staticvkFloat.
class function FromCurrency(const AValue: Currency): TLzNexValue; staticvkCurrency. Mantido separado de Double para não perder as quatro casas fixas do tipo.
class function FromString(const AValue: string): TLzNexValue; staticvkString.
class function FromBytes(const AValue: TBytes): TLzNexValue; staticvkBytes, para colunas binárias e blob.
class function FromDate(const AValue: TDateTime): TLzNexValue; staticvkDate. Só a parte de data entra no texto.
class function FromTime(const AValue: TDateTime): TLzNexValue; staticvkTime. Só a parte de hora.
class function FromDateTime(const AValue: TDateTime): TLzNexValue; staticvkDateTime, data e hora.
class function Identifier(const AName: string): TLzNexValue; staticNome de tabela, coluna ou alias. Não gera bind: o compilador quota e escreve no texto.
class function Raw(const ARaw: IInterface): TLzNexValue; staticEmbrulha um ILzNexRaw. O texto cru entra inline e os binds dele entram na posição correta.
class function SubQuery(const AQuery: IInterface): TLzNexValue; staticEmbrulha um ILzNexQuery para virar subconsulta entre parênteses.
⚠
Unset não chega ao banco

TLzNexBindings.Add recusa um valor vkUnset e levanta ELzNexBuilder. Isso transforma a variável esquecida sem inicializar num erro na hora da montagem, em vez de um parâmetro silenciosamente nulo no update.

Conversão implícita

Seis operadores Implicit permitem escrever o valor direto onde se espera um TLzNexValue, sem chamar construtor.

class operator Implicit(const AValue: Boolean): TLzNexValue→ FromBoolean
class operator Implicit(const AValue: Integer): TLzNexValue→ FromInteger
class operator Implicit(const AValue: Int64): TLzNexValue→ FromInt64
class operator Implicit(const AValue: Double): TLzNexValue→ FromFloat
class operator Implicit(const AValue: Currency): TLzNexValue→ FromCurrency
class operator Implicit(const AValue: string): TLzNexValue→ FromString
 
var V: TLzNexValue;

V := 42;          // vkInteger
V := 'joão';      // vkString
V := True;        // vkBoolean
V := 3.5;         // vkFloat
ℹ
Não há Implicit para TDateTime nem TBytes

TDateTime é um Double disfarçado: um operador implícito para ele seria ambíguo com o de Double, e a data entraria como número. Por isso data, hora e binário exigem o construtor nomeado — FromDate, FromTime, FromDateTime, FromBytes.

Consulta de estado

property Kind: TLzNexValueKind read FKindQual dos formatos está preenchido. Lista completa em Enums.
function IsUnset: BooleanKind = vkUnset.
function IsNull: BooleanKind = vkNull.
function IsBindable: BooleanFalso para vkUnset, vkIdentifier, vkRaw e vkSubQuery — os quatro que vão para o texto do SQL, não para a lista de parâmetros. Verdadeiro para todo o resto, vkNull incluído.

Leitura tipada

Os As* fazem conversão quando ela é segura e levantam ELzNexBuilder quando não é. vkNull e vkUnset sempre devolvem o zero do tipo (0, False, '', nil) em vez de levantar — é o que permite ler uma coluna anulável sem checar antes.

function AsBoolean: BooleanAceita booleano e inteiro (<> 0).
function AsInt64: Int64Aceita inteiro, booleano (Ord) e float (arredonda com Round).
function AsFloat: DoubleAceita float, currency e inteiro.
function AsCurrency: CurrencyAceita currency, float e inteiro.
function AsString: stringFormata tudo que tem representação textual. Data sai yyyy-mm-dd, hora hh:nn:ss, datetime yyyy-mm-dd hh:nn:ss. Recusa vkBytes, vkRaw e vkSubQuery.
function AsBytes: TBytesAceita vkBytes e vkString (copia os bytes da string como estão, sem reencodar).
function AsDateTime: TDateTimeAceita vkDate, vkTime e vkDateTime.
⚠
AsInt64 em string não converte

Não há StrToInt escondido: AsInt64 sobre um vkString levanta ELzNexBuilder. A conversão texto → número é decisão da aplicação, não da biblioteca, porque o que fazer com '12abc' depende do caso.

Ref, Text e Describe

function Ref: IInterfaceA interface guardada por Raw ou SubQuery. nil nos outros kinds.
function Text: stringO campo string interno sem formatação nem checagem de kind. Serve para pegar o nome de um vkIdentifier — é o que Vals usa para extrair o nome da coluna.
function Describe: stringTexto de diagnóstico com kind e conteúdo: integer(1), string('jo'), bytes(16 B), identifier(users.id), <unset>, NULL, raw, subquery. É o que aparece nas mensagens de erro e no log de query.

Coleções de valor

Três apelidos de array, sem método próprio. Aparecem em toda assinatura que recebe lista de valores ou pares coluna/valor.

TLzNexValues = array of TLzNexValueLista posicional. É o que WhereIn, PlaceholderList e TLzNexBindings.ToValues trocam entre si.
TLzNexNamedValue = record Name: string; Value: TLzNexValue; endUm par coluna/valor. Campos públicos diretos, sem getter.
TLzNexNamedValues = array of TLzNexNamedValueLista de pares, na ordem em que foram escritos. É o formato de Insert, Update, dos binds nomeados do SQL cru e das props de conexão.

A ordem importa e é preservada: o SQL gerado lista as colunas na sequência do array, e um insert em lote depende disso para alinhar as linhas. Construa com Vals, ValueList e StringsToValues — veja funções de módulo.

TLzNexFragment

Um pedaço de SQL com os binds dele dentro. Essa é a decisão central do compilador: texto e parâmetros nunca viajam em variáveis separadas, então não existe o bug clássico de concatenar na ordem errada e deixar os ? desalinhados da lista de valores. Todo Concat move o texto e a lista juntos.

Construção

class function Empty: TLzNexFragment; staticTexto vazio, zero binds. Ponto de partida de qualquer acumulação.
class function Lit(const AText: string): TLzNexFragment; staticTexto literal sem bind nenhum. Para palavra-chave, identificador já quotado, operador.
class function Param(const AValue: TLzNexValue): TLzNexFragment; staticTexto ? e exatamente um bind. É o par indissociável.
class function Make(const AText: string; const ABindings: TLzNexBindings): TLzNexFragment; staticTexto e binds já prontos, usado quando o chamador montou os dois lados.

Leitura

function Text: stringO SQL. É o que os testes comparam por igualdade exata.
function Bindings: TLzNexBindingsOs parâmetros, na ordem dos ? no texto.
function IsEmpty: BooleanText = '' — olha só o texto. Um Make('', Binds) conta como vazio e seus binds são descartados por Concat e JoinFragments; se há bind, há ? no texto.

Composição

function Concat(const AOther: TLzNexFragment; const ASep: string = ' '): TLzNexFragmentJunta os dois textos com o separador e concatena os binds na mesma ordem. Se um dos lados está vazio devolve o outro inalterado — é isso que evita separador solto quando uma cláusula não existe.
function Wrap(const ABefore, AAfter: string): TLzNexFragmentEnvolve o texto, tipicamente em parênteses. Fragmento vazio passa intacto, então subconsulta ausente não vira ().
function Prefix(const APrefix: string): TLzNexFragmentSó o começo — 'where ', 'order by '. Também é no-op em fragmento vazio, que é como a cláusula inteira desaparece do SQL.

Wrap e Prefix preservam a lista de binds sem mexer em nada: só o texto muda, as posições relativas dos ? continuam as mesmas. 

var A, B, F: TLzNexFragment;

A := TLzNexFragment.Lit('`age` >=').Concat(TLzNexFragment.Param(18));
B := TLzNexFragment.Lit('`active` =').Concat(TLzNexFragment.Param(True));
F := A.Concat(B, ' and ').Prefix('where ');

Writeln(F.Text);                  // where `age` >= ? and `active` = ?
Writeln(F.Bindings.Describe);     // [integer(18), boolean(True)]
Writeln(F.Bindings.Count);        // 2

TLzNexFragments, JoinFragments e PlaceholderList

TLzNexFragments = array of TLzNexFragmentLista de fragmentos. É o formato dos três campos de TLzNexDdlPlan (Pre, Statements, Post).
function JoinFragments(const AItems: TLzNexFragments; const ASep: string = ' '): TLzNexFragmentJunta a lista com o separador, pulando os vazios — sem vírgula sobrando no fim nem separador duplicado no meio. Os binds saem na ordem dos itens não vazios.
function PlaceholderList(const AValues: TLzNexValues): TLzNexFragmentGera ?, ?, ? com um bind por valor. Lista vazia devolve fragmento vazio — quem chama decide o que colocar no lugar (em WhereIn, 1 = 0).
 
F := PlaceholderList(ValueList([1, 2, 3])).Wrap('(', ')').Prefix('`id` in ');
Writeln(F.Text);                  // `id` in (?, ?, ?)
Writeln(F.Bindings.Count);        // 3

TLzNexBindings

A lista de parâmetros de um fragmento. Cresce dobrando a capacidade (começa em 8), então Count e Length do array interno não coincidem — sempre use Count.

class function Empty: TLzNexBindings; staticLista zerada.
class function One(const AValue: TLzNexValue): TLzNexBindings; staticAtalho para o caso de um único bind.
class function FromValues(const AValues: TLzNexValues): TLzNexBindings; staticLista inteira de uma vez.
procedure Add(const AValue: TLzNexValue)Acrescenta no fim. Levanta ELzNexBuilder se o valor for vkUnset — é a rede que pega variável não inicializada.
procedure AddMany(const AValues: TLzNexValues)Add em cada item, com a mesma checagem.
procedure Append(const AOther: TLzNexBindings)Copia os binds de outra lista, preservando a ordem. É o que Concat chama.
function Count: IntegerQuantos binds de fato existem.
function Items(const AIndex: Integer): TLzNexValueBind na posição, base zero. Índice fora da faixa levanta ELzNexBuilder com índice e total na mensagem, em vez de devolver lixo.
function ToValues: TLzNexValuesCópia exata, com Count elementos — sem o excesso de capacidade.
function Describe: string[integer(1), string('jo')]. Concatena o Describe de cada valor entre colchetes. Usado no log e nas asserções dos testes.
ℹ
Record com array: cópia é rasa

TLzNexBindings é um record cujo campo é um array dinâmico. Atribuir B := A compartilha o array até que um dos dois cresça. Na prática isso não morde porque o compilador só compõe por Concat e Append, que sempre partem de Empty e copiam item por item. Se você montar bindings à mão, parta de Empty e use Append em vez de atribuir.
